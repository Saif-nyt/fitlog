1. Project name: Fitlog

2. Short description: FitLog is a responsive workout library and workout planning web application. Users can browse workouts, view workout details, add exercises to their daily plan, save workouts for later, and track their completed workouts.
 
3. Technologies Used:
- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API
- javascript
 
4. 5 key features of the project:
-  Workout Library: Browse a collection of workouts with essential information such as muscle groups, equipment, duration, calories burned, and rating.
-  Detailed Workout Information: Each workout has a dedicated details page containing its description, difficulty, sets, reps, instructions, equipment, duration, calories, and rating.
-  Responsive User Interface: The application is designed to provide a consistent experience across mobile, tablet, and desktop devices with a clean, dark-themed fitness interface.
-  Personalized Workout Plan: Users can add exercises to their daily plan and view a summary of their selected workouts, including total exercises, workout duration, and estimated calories.
-  Save and Track Workouts: Users can save workouts for later and mark exercises as completed when they finish their workout.
